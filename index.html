Mathematical Formulation & Concepts

This mini-project demonstrates the application of Linear Algebra & Vector Calculus to model and analyze web page importance via the PageRank Markov process. The system executes eight sequential mathematical stages, where each stage's output serves as the input to the subsequent stage.

1. Concept 1: Matrices (Adjacency & Transition Matrices)

Consider a directed web graph \(G = (V, E)\) with \(n\) pages \(P_1, P_2, \dots, P_n\). The hyperlink structure is represented by the Link / Adjacency Matrix \(A \in \mathbb{R}^{n \times n}\):

\[ A_{ij} = \begin{cases} 1 & \text{if page } P_j \text{ contains a hyperlink pointing to page } P_i \\ 0 & \text{otherwise} \end{cases} \]

The out-degree of page \(P_j\) is the sum of outgoing hyperlinks: \(d_j = \sum_{i=1}^n A_{ij}\).

2. Concept 2: Markov Chains & Column Stochastic Normalization

A random web surfer at page \(P_j\) navigates to page \(P_i\) with probability proportional to the outgoing links. The Transition Matrix \(M \in \mathbb{R}^{n \times n}\) is column-stochastic:

\[ M_{ij} = \begin{cases} \frac{A_{ij}}{d_j} & \text{if } d_j > 0 \\ \frac{1}{n} & \text{if } d_j = 0 \quad (\text{Dangling Node / Dead End}) \end{cases} \]

Every column sum satisfies \(\sum_{i=1}^n M_{ij} = 1\), establishing a discrete-time Markov chain.

3. Google Damping Matrix & Perron-Frobenius Regularization

To eliminate dead-ends and spider traps (absorbing cycles) and guarantee ergodicity, a damping factor \(d \in (0, 1)\) (typically \(d = 0.85\)) is introduced:

\[ G = d M + \frac{1 - d}{n} \mathbf{E} \]

where \(\mathbf{E} = \mathbf{1}\mathbf{1}^T\) is an \(n \times n\) matrix of all ones. Matrix \(G\) is strictly positive (\(G_{ij} > 0\) for all \(i, j\)), primitive, and column-stochastic.

4. Concept 3: Vectors & Linear Transformations

The ranking state at iteration \(k\) is represented by probability vector \(v^{(k)} \in \mathbb{R}^n\) satisfying \(v_i^{(k)} \ge 0\) and \(\|v^{(k)}\|_1 = \sum_{i=1}^n v_i^{(k)} = 1\). The transition from step \(k\) to \(k+1\) is a linear transformation \(T: \mathbb{R}^n \to \mathbb{R}^n\):

\[ v^{(k+1)} = T(v^{(k)}) = G v^{(k)} \]

5. Power Iteration & Convergence Analysis

Repeated application yields:

\[ v^{(k)} = G^k v^{(0)} \]

The convergence measure is evaluated at each step using the Euclidean \(\ell_2\) and \(\ell_1\) norm differences:

\[ \delta_k = \|v^{(k+1)} - v^{(k)}\|_2 = \sqrt{\sum_{i=1}^n \left(v_i^{(k+1)} - v_i^{(k)}\right)^2} < \epsilon \]

Rate of Convergence: By the Perron-Frobenius theorem, the convergence rate is bounded by the magnitude of the second dominant eigenvalue \(|\lambda_2| \le d\). The spectral gap is \(\gamma = 1 - |\lambda_2|\).

6. Concept 4: Eigenvalues & Eigenvectors (Verification)

At convergence (\(k \to \infty\)), the ranking vector approaches a stationary distribution \(v^*\):

\[ G v^* = 1 \cdot v^* \iff (G - I) v^* = \mathbf{0} \]

Thus, the steady-state PageRank vector is the principal eigenvector of \(G\) associated with the dominant eigenvalue \(\lambda_1 = 1\). Our software verifies this analytically by setting up the linear system:

\[ \begin{bmatrix} (G - I)_{1:n-1, :} \\ \mathbf{1}^T \end{bmatrix} v^* = \begin{bmatrix} \mathbf{0} \\ 1 \end{bmatrix} \]

and solving via Gaussian Elimination with partial pivoting, confirming \(\|v_{\text{power}}^* - v_{\text{eigen}}^*\|_2 \approx 0\).

Viva Voce & Presentation Preparation Guide

Use this curated question-and-answer guide to prepare for your project demonstration, viva evaluation, and viva voce presentation.

Q1. What are the four prescribed mathematical concepts used in this mini-project? Concept Alignment

Answer:

  1. Matrices: Directed link adjacency matrix \(A\), column-stochastic transition matrix \(M\), and the irreducible Google matrix \(G\).
  2. Vectors: Probability state vectors \(v^{(k)}\), uniform initial ranking vector \(v^{(0)}\), and stationary steady-state ranking vector \(v^*\).
  3. Linear Transformations: The state update equation \(v^{(k+1)} = G v^{(k)}\) is a linear operator \(T(v) = Gv\) that preserves probability mass (\(\|v\|_1 = 1\)).
  4. Eigenvalues and Eigenvectors: The steady-state ranking vector is the eigenvector associated with dominant eigenvalue \(\lambda = 1\) satisfying \(G v^* = v^*\).
  5. Markov Chains: Formulated as a discrete-time ergodic Markov chain over the finite state space of web pages.
Q2. Why is the transition matrix M normalized by columns instead of rows? Markov Properties

Answer: In the random surfer model, the state vector is a column vector \(v\) where \(v_i\) represents the probability of being on page \(i\). The probability of transitioning from page \(j\) to page \(i\) is \(M_{ij}\). To ensure conservation of probability, the sum over all possible destinations \(i\) given current page \(j\) must equal 1: \(\sum_{i=1}^n M_{ij} = 1\). Hence, every column of \(M\) must sum to 1 (column-stochastic matrix).

Q3. What is a "Dangling Node" and how does your software handle it? Numerical Stability

Answer: A dangling node is a web page with no outgoing hyperlinks (out-degree \(d_j = 0\)). If unhandled, column \(j\) in \(M\) would contain all zeros, violating the stochastic property and causing probability mass to leak to 0 over iterations. Our software detects dangling nodes and replaces their column with uniform teleportation: \(M_{ij} = \frac{1}{n}\) for all \(i\), modeling a user opening a random bookmark or typing a new URL.

Q4. What is a "Spider Trap" and why is the damping factor d introduced? Graph Anomalies

Answer: A spider trap is a group of pages (or a single self-looping page) with links only amongst themselves. A random surfer entering this group can never leave, absorbing all probability mass so other legitimate pages end up with rank 0. The Google damping factor \(d\) (typically \(0.85\)) introduces a teleportation term \(\frac{1-d}{n}\mathbf{E}\). With probability \(d\), the surfer follows links; with probability \((1-d)\), they jump to any random page on the web. This guarantees the Markov chain is irreducible and aperiodic.

Q5. Why does the dominant eigenvalue always equal 1 (\(\lambda_1 = 1\))? Perron-Frobenius Theorem

Answer: Since \(G\) is column-stochastic, its transpose \(G^T\) is row-stochastic: \(G^T \mathbf{1} = \mathbf{1}\), meaning \(\mathbf{1} = [1, 1, \dots, 1]^T\) is an eigenvector of \(G^T\) with eigenvalue \(\lambda = 1\). Because a matrix and its transpose share the same eigenvalues, \(G\) must also have \(\lambda = 1\) as an eigenvalue. Furthermore, by the Perron-Frobenius theorem for strictly positive matrices, \(\lambda = 1\) is strictly dominant (\(|\lambda_i| < 1\) for all \(i \ge 2\)), unique, and its associated eigenvector has strictly positive components.

Q6. What role does the second eigenvalue \(\lambda_2\) play in convergence? Spectral Gap

Answer: The asymptotic rate of convergence in power iteration is determined by the ratio \(\left|\frac{\lambda_2}{\lambda_1}\right| = |\lambda_2|\). The error at iteration \(k\) satisfies \(\|v^{(k)} - v^*\| = \mathcal{O}(|\lambda_2|^k)\). Since \(|\lambda_2| \le d\), choosing \(d = 0.85\) guarantees fast exponential convergence in approximately 25 to 40 iterations regardless of web size! The difference \(1 - |\lambda_2|\) is called the spectral gap.

Q7. How does the software verify the power iteration result analytically? Software Verification

Answer: The software formulates the homogeneous nullspace problem \((G - I)v = 0\) subject to \(\sum_{i=1}^n v_i = 1\). By replacing one linearly dependent row of \((G - I)\) with the all-ones vector \([1, 1, \dots, 1]\) and right-hand side \([0, \dots, 0, 1]^T\), it solves the non-singular linear system using Gaussian Elimination with partial pivoting. It then computes the Euclidean distance \(\|v_{\text{power}} - v_{\text{eigen}}\|_2\) and residual \(\|G v - v\|_2\), confirming numerical equality down to \(< 10^{-7}\).

Python Implementation & CLI Script

Alongside this web application, a complete, standalone Python implementation is provided in the repository under python/pagerank_analyzer.py. It requires zero external libraries (pure Python standard library) and runs anywhere.

How to Run the Python Script:

# Run the default 4-node academic demonstration
python3 python/pagerank_analyzer.py

# Run with custom damping factor and tolerance
python3 python/pagerank_analyzer.py --damping 0.85 --tolerance 1e-8 --preset star

# Run automated mathematical verification test suite
python3 python/demo_example.py

Features of the Python Implementation:

  • Builds the Adjacency Matrix \(A\), Transition Matrix \(M\), and Google Matrix \(G\).
  • Handles dangling nodes with uniform teleportation.
  • Executes Power Iteration with full iteration log and Euclidean error tracking.
  • Solves the stationary linear system \((G - I)v = 0\) via Gaussian Elimination.
  • Exports convergence history to CSV and JSON formats.
